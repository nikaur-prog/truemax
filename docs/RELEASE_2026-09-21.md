# Capture, calibration workflow and report release

The owner approved merging the pending build on 21 September 2026. This release
includes the previously committed Max presence/conversation work and the reviewed
capture, calibration-workflow, measurement-detail and search-content changes.

## Included

- Stable front-camera auto-framing and source-detail checks across phone/laptop
  aspect ratios, without cropping retained capture pixels.
- Larger face-centred mobile result photos, aligned overlays and short-landscape
  reading space. Existing desktop result composition is preserved.
- Upload/paste skip redundant photo acceptance; camera captures retain it.
- Cross-region measurement navigation, visible celebrity reference portraits,
  and clearer measurement/reference-fit explanations.
- Calibration record identity/pair/reference safeguards and fixed cloud failure
  diagnostics. Original automatic and reviewed coordinates remain separate.
- Static measurement guides, truthful search targeting and opt-in analytics
  groundwork. Google collection remains conditional on explicit configuration
  and consent; field-vitals and confirmed revenue reporting are not activated.

## Not an accuracy activation

The placement residual experiment and side-band-fit experiment remain offline.
This release does not replace the live side scoring curve, establish anatomical
accuracy or validate population percentiles. Existing synthetic reviews are
development evidence; the owner does not need to repeat them.

The next useful validation pilot is ten consenting adults with two independently
captured front photos and two independently captured same-side profiles each.
Keep anonymous IDs, original images and all-capture diagnostics private; leave
ratings blank. Freeze the candidate before examining these new identities and
keep all photos of each person together when evaluating unseen people. Forty
photos still represent only ten independent people.

Independent review of ambiguous landmark definitions and a second blind point
reviewer would add evidence without another bulk collection. Attractiveness
score calibration is separate and needs explicitly scoped, defensible reference
ratings; two external overall values are insufficient.
