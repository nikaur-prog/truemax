## Calibration safeguards, not completed calibration

The preserved repairs also correct side coverage counting to use side metric definitions and finite measurements. A collection target no longer claims that a set is validated. Benchmark comparison requires explicit definition/unit confirmation, reports differences in native units and gives each person equal weight across repeated captures. Competitor scores are context, not fitting targets. Tests are in `src/engine/calibrationSet.test.ts` and `src/engine/benchmarkAgreement.test.ts`.

A separate development-only synthetic pilot workspace is documented in [LOCAL_SYNTHETIC_CALIBRATION_PILOT.md](LOCAL_SYNTHETIC_CALIBRATION_PILOT.md). It is not a production entry, a real-person accuracy study, or proof that filename-paired images preserve identity. Its local diagnostic results must stay unverified. No scoring parameters were fitted and no FaceIQ results were obtained in this audit. The broader study remains in [FACEIQ_COMPARISON_AND_CALIBRATION_PLAN_2026-09-07.md](FACEIQ_COMPARISON_AND_CALIBRATION_PLAN_2026-09-07.md).

The subsequent signed-in FaceIQ access check succeeded. Its built-in private export supplied 11 analysis metadata records and 22 photos but no measurements, scores or coordinates. No new batch was submitted, no public share link was created, and the private export was not committed. [FACEIQ_DATA_ACCESS_2026-09-09.md](FACEIQ_DATA_ACCESS_2026-09-09.md) records the missing fields and a draft request for complete data and bounded automated-access permission.

[CALIBRATION_NEXT_STEPS_2026-09-09.md](CALIBRATION_NEXT_STEPS_2026-09-09.md) separates owner actions, engineering work, independent annotation and score calibration. The existing Calibrate corpus export is a rated subset, not an automatic training run or a complete landmark export. The signed-out local Calibrate runtime check reached the expected owner access gate; no gate was bypassed and no authenticated video export was claimed.

The first local batch subsequently completed all 40 synthetic images and 20 pairs. It exposed an unresolved placement problem: 15 profiles reproduce the same 117.457752-degree gonial angle from three template-backed jaw points and a default head-depth ratio. All 20 profiles pass geometric integrity despite visually flagged placement errors. Internal head-mask occupancy is not landmark correctness. The default cloud fusion can change the hinge but retains the device jaw corner and chin bottom, so a cloud call alone cannot correct the whole triplet. The next step is independent point annotation and per-point provenance, not a scoring offset or new ideal. Pixel hairline was also unavailable on all 20 fronts. A second pass on the same 40 input hashes reproduced every point, all 960 finite raw measurements and all scores exactly; this is same-input consistency, not anatomical accuracy. Two seed-direction metadata values disagree with final geometry, while both final measured directions are correct. Detailed per-input diagnostics remain local and gitignored; no images, point arrays or private identifiers are published here. This batch establishes neither an accuracy percentage nor a real-user score distribution.

## Explicitly unchanged or still open

- Personal weekly scans and scans of other people remain distinct allowance buckets. No Free paywall, pricing or quota-policy change was made in this audit.
- The first morph `POST` still needs server-backed idempotency/recovery for the case where a render starts but its initial response is lost before the client receives a job ID. The known-job fix does not solve that case or survive every page reload. Do not claim duplicate billing is impossible.
- No physical iPhone/iPad test, Safari memory/thermal endurance run or real camera permission/background-resume sweep was completed here. Mobile viewport testing is not a substitute.
- No paid cloud side-placement evaluation or FaceIQ benchmark was run. Placement accuracy, long-tail failures, real end-to-end request latency and rollout suitability still require the consented held-out study. The local harness excludes browser upload, authentication and quota latency.
- The surface gonial-angle reference remains unvalidated for the chosen photographic landmarks. Rejecting degenerate geometry does not establish anatomical accuracy.
- No new database migration, production authentication change, live purchase or payment-system certification was performed. Existing deployed schema state was not re-audited by this report.
- Max animation work was left unchanged. The image-first UGC and carousel documents are separate plans, not implemented production features or evidence of achievable personal transformations.
