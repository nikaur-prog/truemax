Three checks before interpreting a number

  1. Placement: are the marked points on the intended visible features? A correctly drawn line between incorrect points still produces an incorrect measurement.
  2. Construction: which points and baseline are used? “Jaw angle” can refer to different constructions. A frontal outline, a side-photo surface angle and an X-ray measurement are not interchangeable.
  3. Reference: what does the comparison actually represent? Agreement with a model range is different from a model score and different again from demonstrated accuracy.

How to read the units

Degrees describe an angle. A ratio has no physical unit when both lengths come from the same coordinate system. A percentage may express one distance relative to a reference length, not a population percentile. TrueMax's side lip-to-E-line values, for example, are normalized by nose-bridge-to-chin-bottom distance. They are not millimetres.

A worked ratio makes the distinction concrete: if the measured nose width is 42 image units and mouth width is 60, their ratio is 42 ÷ 60 = 0.70. Resizing both distances equally leaves 0.70 unchanged. Changing pose or placing either endpoint differently can change it.

What makes a comparison useful?

Use the same image, the same view and the same measurement definition. Record the raw value separately from any rating. When checking change over time, keep the camera setup and expression consistent and inspect the landmarks before interpreting a difference.

More measurements do not automatically mean better evidence

Several measurements can reuse the same points. One misplaced jaw corner can affect multiple results. A long report is not independent confirmation that every number is right, and the number of usable readings depends on the photo.
